# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub Security Advisories](https://github.com/perisicnikola37/react-dotnet-playwright-e2e-starter/security/advisories/new).
You can expect an acknowledgement within a few days.

## Notes for users of this starter

- Never run tests that create or delete data against production.
- Saved browser sign-ins and tokens are credentials: keep them out of the repository (`.gitignore` already excludes `.env*`).
- Use dedicated test accounts, never real user accounts.
