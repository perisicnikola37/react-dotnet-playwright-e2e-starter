Add a Playwright test dashboard to your React app

Testers and developers start UI tests from a page in your app, watch every test pass or fail live, re-run the failures with one click and share an HTML report with screenshots, steps and Playwright traces. ASP.NET Core + React + Playwright for .NET + xUnit v3.

Use this template Open the live demo Add it to an existing app

Everything a UI test run needs, inside your app

No separate test server, no CI login for testers. Three packages that plug into the app you already have.

▶ Start runs from the browser

Run all tests or a category (Smoke, Regression) from a React page. Runs are queued, one at a time, with a timeout.

⏱ Live progress

Each test shows as queued, running, passed or failed while the run is still going, with progress and time spent.

🔁 Re-run failed tests

Re-run everything, only the failed tests or the same selection from the dashboard with a single click.

📸 Failure evidence

Screenshot, page HTML, URL, browser console, named steps and the Playwright trace for every failed test.

📄 Shareable HTML report

Every run writes a standalone report.html you can attach to a CI build, a ticket or an email.

🔒 Safe by default

Off in Production unless you opt in, works with your auth, short-lived iframe tokens and sandboxed evidence files.

How it works

The React page calls your API, the API runs your Playwright tests and the dashboard follows the run.

PackageWhereWhat it does
E2eStarter.PlaywrightYour UI test project (NuGet)Playwright + xUnit v3 base classes: one browser per run, a context and trace per test, failure evidence, live progress events.
E2eStarter.AspNetCoreYour ASP.NET Core API (NuGet)AddAutomatedTests() + MapAutomatedTests(): start, list, re-run and serve runs and dashboards.
E2eStarter.Reportersdotnet toolTurns the TRX result and evidence into data.json, the dashboard and report.html.
@perisicnikola37/e2e-starter-reactYour React app (npm)<AutomatedTestsPage />: start runs, see history and the live dashboard.

Quick start

Already have a React app with an ASP.NET Core backend? Three steps. Starting from scratch? Use the template.

Write UI tests

Reference E2eStarter.Playwright and inherit from UiTestBase.

public sealed class ItemsTests(SuiteFixture suite)
    : UiTestBase(suite)
{
    [Fact]
    public async Task Adds_an_item()
    {
        Step("Open the page");
        await Page.GotoAsync("/");
        // ...
    }
}

Add the API endpoints

Reference E2eStarter.AspNetCore in your API.

builder.Services.AddAutomatedTests(
    builder.Configuration.GetSection("AutomatedTests"));

app.MapAutomatedTests(); // /api/automated-tests

Add the React page

Install @perisicnikola37/e2e-starter-react.

import { AutomatedTestsPage } from
  "@perisicnikola37/e2e-starter-react";

<Route path="/tests"
  element={<AutomatedTestsPage />} />

Full guide, configuration and CI setup: README on GitHub.

FAQ

How do I add a Playwright test dashboard to my React app?

Add E2eStarter.AspNetCore to your ASP.NET Core API, call AddAutomatedTests() and MapAutomatedTests(), then render <AutomatedTestsPage /> on any React route. Testers can start runs, watch them live and open the report from that page.

Does it work with Playwright for Node.js (@playwright/test)?

The runner and reporter are built for Playwright for .NET with xUnit v3. The React page and dashboard only talk to the HTTP endpoints, so another runner can be plugged in, but the starter ships the .NET pieces.

Is it safe to expose the endpoints?

They are disabled in Production unless you set AllowInProduction, can be protected with RequireAuthorization(), the iframe uses short-lived dashboard tokens and evidence files are served with a sandbox Content-Security-Policy.

Can I share a report without the app running?

Yes. Every run writes a standalone report.html with screenshots, steps, console output and the Playwright trace. Upload it as a CI artifact or send it to anyone.

Can I run the same tests in CI?

Yes. The tests are a normal dotnet test project; the repository includes GitHub Actions workflows that run them and publish the report.

What does it cost?

Nothing. It is open source under the MIT license.
